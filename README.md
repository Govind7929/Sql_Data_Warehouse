SQL Data Warehouse Project

This project demonstrates how to build a modern data warehouse using Microsoft SQL Server. It covers the complete process of converting raw data into meaningful business insights.

Project Overview

The project focuses on:

Collecting raw data
Cleaning and transforming data
Loading data into structured warehouse tables
Designing a star schema (fact and dimension tables)
Running analytical queries for reporting

Tools Used

Microsoft SQL Server
T-SQL
SQL Server Management Studio (SSMS)

Process

Load raw data into staging tables
Clean and transform the data
Create dimension tables
Create fact tables
Execute analytical queries

Example Analysis

Total sales by region
Monthly revenue trends
Top-selling products
Customer analysis

How to Run

Clone the repository
Open the scripts in SSMS
Execute them in order: Database → Tables → ETL → Queries
